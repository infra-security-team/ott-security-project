# 작업 시작 순서

**대상:** 모든 팀원. **첫날 목표:** 담당 작업과 기록 위치 확인, 필요한 연결 조건 정리, 설계 초안 시작.

| 순서 | 확인·작성 내용 | 완료 기준 |
|---|---|---|
| 1. 담당 확인 | [담당표](../docs/01-planning/team-roles/README.md)와 [일정표](../docs/01-planning/wbs.md)에서 내 첫 작업 번호 확인 | 작업 페이지의 목표·기한·선행 조건 파악 |
| 2. 시작 댓글 | 내 첫 작업 페이지에 아래 세 항목 기록 | 담당 일·첫 행동·필요 정보 표시 |
| 3. Notion 준비 | 팀이 공유한 개인 기술서 페이지 또는 [임시 작성 항목](../docs/templates/technical-detail-template.md) 준비 | 담당 범위·구성 그림 초안·필요 정보 기록 |
| 4. 작업·기록 | 실습 중 코드·설정 이유·오류·실제 결과를 Notion에 기록 | 계획과 실제 결과 구분 |
| 5. 하루 마감 | 작업 페이지에 한 일·자료 링크·막힌 점·다음 행동 기록 | 진행 상태와 남은 일 확인 가능 |

**시작 댓글 예시**
```text
담당 일: 본사 네트워크 주소와 연결 경로 설계
첫 행동: 장비·주소 대역 확인
필요 정보: 서비스 서버 주소, 캐나다망 연결 조건
```

**마감 댓글 예시**
```text
오늘 한 일: 본사망 구성도 초안 작성
자료 링크: <팀원이 열 수 있는 Notion 또는 GitHub 주소>
막힌 점: 캐나다망 주소 대역 미확정
다음 행동: M5와 주소 협의 후 구성도 수정
```

작업 페이지 권한·팀 Notion 접근 문제: [공동 준비 작업 #6](https://github.com/infra-security-team/ott-security-project/issues/6)에 기록. 다음 단계: [매일 기록 방법](WORK.md).
