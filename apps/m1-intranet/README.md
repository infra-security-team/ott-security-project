# M1·M2 | 한국·독일 공통 사내 게시판 웹

**팀명 Team Blocks · 보안 컨설팅 회사 NetBlocks · 가상 OTT 고객사 OTTer**

**프로젝트명:** OTTer Shield — 한국·캐나다 OTT 하이브리드 인프라 구축 및 보안 컨설팅

**상태: 실행 코드 등록 전 · 배포 대상: M1 한국·M2 독일 본사 사내망 · 코드 개발: M5 유은혜 · 배포: M1 유용수·M2 윤서영**

한국·독일 본사 직원이 사내에서 사용하는 공통 게시판 코드를 이 폴더에 등록합니다. 국가별 DB·계정·환경변수·DNS는 분리하고 코드는 공유합니다. 공개 OTT 메인 웹과 캐나다 Store 코드를 함께 넣지 않습니다. M1·M2는 M5가 제공한 앱을 각자 배포·운영하고, 필요한 통신을 M5와 함께 시험합니다.

현재 기술 스택·앱 실행 방식·게시판 세부 기능은 코드 등록 시 명시합니다. 프론트엔드와 백엔드를 분리하는지 확인하기 전에 불필요한 하위 폴더를 만들지 않습니다.

## 코드 등록 후 채울 실행 정보

- 실제 프레임워크·버전과 필요한 실행 환경
- 실행·빌드 명령, 환경변수 이름과 DB 준비 방법
- 사내 접속 경로 및 접근 권한
- 게시판의 실제 기능·정상 요청·비인가 요청 검증 결과

비밀번호·API 키·개인키는 등록하지 않습니다. 배포 방식과 연결값은 구축 후 검증 결과로 기록합니다.
