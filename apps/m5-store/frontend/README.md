# M5 Store | React 화면

**팀명 Team Blocks · 보안 컨설팅 회사 NetBlocks · 가상 OTT 고객사 OTTer**

**프로젝트명:** OTTer Shield — 한국·캐나다 OTT 하이브리드 인프라 구축 및 보안 컨설팅

**상태: 실행 코드 등록 전 · 코드 개발·배포: M5 유은혜**

이 폴더에는 캐나다 Store의 React 화면 원본 코드를 등록합니다. 한국 OTT 메인 서비스의 같은 이름 폴더와 구분합니다.

실행 코드가 등록되면 실제 환경·버전, 빌드·실행 명령, 환경변수 이름, 연동 조건과 검증된 버전을 작성합니다. 비밀값은 등록하지 않습니다.
