# 팀 계획 설계

이 폴더는 팀이 **함께 합의한 설계 그림과 구조**를 모읍니다. 실제 인프라 설정 명령, 공격 과정, 시험 로그는 개인 Notion 기술서에 기록합니다.

| 자료 | 담당·작성 시점 | 적을 내용 |
|---|---|---|
| [전체 구성도](architecture.md) | PL과 각 망 담당, 팀 설계 합의 때 | 본사·서비스·백업·캐나다망의 연결과 서비스 흐름. 계획/확정 구분 |
| [Class Diagram](class-diagram.md) | M5, 앱 설계 또는 주요 코드 구조 확정 때 | 실제 주요 클래스의 책임과 관계 |
| [ERD](erd.md) | M5와 M3, DB 구조 합의 때 | 테이블·기본키·외래키와 관계 |

아직 그림을 만들지 않았다면 `미작성` 상태를 유지합니다. 실제 구성과 달라지면 수정 날짜와 결정 내용을 남깁니다.
