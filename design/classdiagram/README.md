# 클래스 다이어그램

서비스별 클래스·역할·메서드·연결 관계를 관리합니다.

| 서비스 | 자료 | 상태 |
|---|---|---|
| 사내 게시판 | [intranet](intranet/README.md) | M5 작성 핵심 구조 등록 · 전체 설계 최종 확정 전 |
| OTT 메인 | [ott](ott/README.md) | 미작성 |
| Store | [store](store/README.md) | 미작성 |

요구사항·ERD 확인 → 클래스 구성과 처리 흐름을 M5와 검토 → Mermaid 코드 제공 → M5가 draw.io에서 생성·수정 → 파일 확인 후 등록 순으로 진행합니다.

AI가 제안한 전체 클래스 도면을 승인 없이 최종본으로 올리지 않습니다. 기존 게시판 v1.0은 [미승인 제안 초안](intranet/drafts/README.md)으로 분리했습니다. 현재 전체 클래스 최종 확정본은 없습니다.

개발 설계·구현·기능 검증은 M5 담당이며 M3의 개발 검토를 전제로 하지 않습니다.
