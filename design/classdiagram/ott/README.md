# OTT 메인 클래스 다이어그램

**상태:** 미작성

로그인·권한, 콘텐츠 목록·영상 재생과 AI 자막의 데이터·코드 구조를 작성합니다.

M5와 최신 요구사항·ERD·클래스별 책임을 확인한 뒤 Mermaid 코드를 제공하고, M5가 draw.io에서 작성·수정합니다. 확인 전 자료를 최종본으로 등록하지 않습니다.

사내 게시판 설계와 구분해 관리하며 다른 서비스와의 계정·데이터 공유 여부를 임의로 정하지 않습니다.
