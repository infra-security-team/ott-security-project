4. **표시할 정보:** VLAN ID, CIDR/IP 대역, 기본 게이트웨이, 물리/가상 NIC·스위치 또는 포트그룹 명칭(미확정 시 TBD), DHCP/고정 IP, 정상 통신 목적지·포트·프로토콜.

6. **클라우드:** 필요 시 AWS 영역을 점선 상자로 분리하고 AWS가 접속하는 경로(공개 HTTPS / 백업→S3)만 표시. EC2·S3·CloudFront의 역할 차이 표시.

## 도형과 선의 표준
- **사각 경계:** 본사 / 서비스 / DR / 캐나다 / AWS를 구획
- **내부 하위 경계:** 직원·관리·DMZ·APP·DATA·백업·시험 VLAN
- **실선:** 정상 업무 트래픽, **점선:** VPN 보호/논리 터널(물리 NIC 연결선과 별도)
- **빨간 점선:** AS-IS 격리 시험에서 재현할 비인가 접근 경로
- **TO-BE 도면:** 같은 AS-IS 페이지 복제 후 변경된 ACL/방화벽/관리 경로만 강조. 최종 정책은 실제 시험 후 확정.
- 컬러만 의존하지 말고 각 선 옆에 '정상/시험/차단', 포트, 출발지→목적지 라벨도 표기.
