# ERD

서비스별 테이블·기본 키·외래 키·관계를 관리합니다. 사내 게시판의 ERD를 OTT·Store 설계로 대신 사용하지 않습니다.

| 서비스 | 자료 | 상태 |
|---|---|---|
| 사내 게시판 | [intranet](intranet/README.md) | M5 작성 이미지 등록 · 최종 확인 전 |
| OTT 메인 | [ott](ott/README.md) | 미작성 |
| Store | [store](store/README.md) | 미작성 |

M5가 요구사항과 데이터 항목을 정하고 검토한 뒤 draw.io에서 도면을 만듭니다. 실제 DB 구현 후 스키마와 대조합니다.
