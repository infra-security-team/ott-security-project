# 사내 게시판 ERD

**상태:** M5 작성 이미지 등록 · 최종 확인·DB 구현 전

한국·독일 공통 게시판. 국가별 DB·계정·환경설정은 분리합니다.

![사내 게시판 ERD](post_ERD.drawio.png)

[draw.io 편집 정보가 포함된 PNG](post_ERD.drawio.png)

직원과 게시글은 1:N 관계입니다. 작성자 연결은 익명 글에서도 유지합니다. 칭찬은 익명 선택, 점심은 닉네임 표시를 사용합니다. 제목·본문은 공백만 있으면 등록을 거절합니다. 사진 1장은 선택 기능이며 텍스트 기능 이후 구현할 계획입니다.

문자열 길이·NULL 허용·기본값·인덱스·삭제 정책과 사진 저장 조건은 구현 전에 확인합니다. 클래스 제안의 추가 기술 선택이 이 ERD에서 모두 확정된 것은 아닙니다.
