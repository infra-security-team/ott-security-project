| 구역 | 경계 장비·내부 구성 | 보안 역할 |
|---|---|---|
| M1 유용수 | R1(GNS3 내 라우터) → UTM1(Sophos UTM 9) → GNS3 L2 VLAN 스위치 | UTM이 VLAN 게이트웨이·접근 통제·업무 VPN. 서버 10·직원 PC 6·관리 PC 2·스위치 10 보존 |
| M2 윤서영 | R2(VyOS) → UTM2(Sophos UTM 9) → SOC·TEST·MGMT | SOC 진입 경로의 Suricata, Wazuh 중앙 시스템·로그 분석, Bastion 관리 경로 |
| M3 홍은서 | R3(VyOS) → UTM3(Sophos UTM 9) → DMZ·APP·DATA·MGMT | 현지 Suricata가 DMZ·APP·DATA 경계를 각각 검사. Nginx·K8s·DB·Argo CD |

## 통신·관제·차단 기준

- 교실 공통 연결망을 사용하되 각 내부 VM은 자기 UTM을 기본 게이트웨이로 사용합니다. 내부 VM에 우회용 교실 Bridged NIC를 붙이지 않습니다.
- 업무 VPN은 **M1–M5, M1–M4, M3–M4**를 유지합니다. 보호 대역·반환 경로·NAT 예외를 양쪽에 맞춥니다.
- **M2 관제·관리 경로는 업무 VPN 허브 경유 대신 교실 연결망을 통한 직접 라우팅**으로 구분합니다. 필요한 통신만 허용합니다.
- Wazuh 중앙 시스템은 M2에 한 세트(Manager·Indexer·Dashboard), Agent는 각 감시 대상에 설치합니다. UTM 자체 로그와 센서 이벤트도 중앙 수집합니다.
- Suricata는 **M2 1개 전달 쌍+관리 NIC(3 NIC)**, **M3 3개 전달 쌍+관리 NIC(7 NIC)**의 통과형 설계입니다. 같은 VMnet으로 앞뒤를 우회 연결하지 않습니다.
- AS-IS는 탐지 모드, TO-BE는 선정한 IPS 차단 규칙을 적용합니다. `ips` 모드와 `drop` 규칙을 각각 검증합니다. 센서 장애 시 통신 중단 가능성도 점검합니다.
- M1·M4·M5의 모든 패킷을 M2 센서가 자동으로 본다고 표시하지 않습니다. SSH/TLS 본문과 서버 내부 파일 행위는 관련 서버 로그로 보완합니다.

## 보안 시나리오와 정상 기능

| 시나리오 | 시험 경로·주된 차단 수단 | 유지할 정상 기능 |
|---|---|---|
| S01 직원의 관리 접속 | M1 직원 → 교실 라우팅 → M2 센서 → SSH 시험 서버 / UTM2 접근 정책 | 승인 관리자·Bastion 접속, 포털·DNS |
| S02 반복 SSH 인증 실패 | M2 TEST → UTM2 → 센서 → SSH 서버 / Wazuh 경보·서버 반복 제한 | 정상 관리자 로그인·관제 수집 |
| S03 관리 API 노출 | M2 TEST → M3 UTM·APP 센서 → K8s 관리 API / UTM3 접근 정책·K8s 권한 | 고객 앱·승인 관리·Argo CD |
| S04 백업 파일 열람 | M4 같은 LAN의 시험 계정 → 백업 서버 / 파일 권한·읽기 감사 | 승인 백업·복원 |
| S05 직원의 DB 접근 | M5 → 업무 VPN → M1 → M3 DATA 센서 → 시험 DB / UTM3 접근 정책 | 포털·DNS·앱 DB·백업·복제 |

S05 응답도 M1·VPN을 경유해야 합니다. 관제 수집, 접속 성공, 경보 발생, 차단 성공은 서로 다른 결과로 기록합니다.

## 구축 전에 남은 확인

- 팀에서 정한 주소표를 실제 경계 장비·NIC MAC과 대조해 도면의 임시 기호를 실값으로 기록합니다.
- M1 단말의 GNS3 QEMU Linux 배치는 구체화한 제안이며, 중첩 가상화·기존 이미지·32GB 기동량을 확인합니다. 자산 수·IP는 보존합니다.
- M3의 관리망·센서는 전후 증거 수집을 위해 AS-IS부터 사용합니다. 센서 전달·중첩 ESXi·K8s 대역 중복·설치 버전을 점검합니다.
- 교실 실습용 Nginx 화면과 `/api` 진입점은 외부 고객 API 공개와 구분합니다. 외부 공개에는 상위 NAT·DNS·인증서 조건이 필요합니다.
- AWS EKS 관리용 SSM EC2·IAM·출구는 추가 구성 제안입니다. 비용·권한과 AWS 로그 수집을 확인합니다. 사내 VPN이 AWS까지 자동 연결되지는 않습니다.

명칭·설계 문서 갱신은 실제 인프라의 구축·시험 완료가 아닙니다. 기존 상세 가이드와 차이가 있으면 v1.2와 팀의 최신 확정 결정을 기준으로 대조합니다.
