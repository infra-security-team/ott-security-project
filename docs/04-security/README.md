# 04 · 전 망 보안 컨설팅
- `assessment/`: 망별 AS-IS 위험 분석·승인된 재현
- `remediation/`: 망별 TO-BE 보안 정책·솔루션·차단 설정
- `validation/`: **동일 조건 재검증**과 Wazuh·IDS 경보 및 정상서비스 회귀 테스트

**M2는 중앙 보안 정책·관제 리드**, 모든 망 담당자는 자기 영역의 방화벽/VLAN/VPN/호스트 보안을 직접 구현하고 증빙을 작성합니다.
템플릿: [보안 진단서](../templates/security-assessment-template.md)


## 먼저 시나리오를 정의
| ID | 담당 | 검증할 문제 |
|---|---|---|
