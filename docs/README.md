# 프로젝트 문서

**자료 위치 선택 기준:** 시작·작성 방법은 [팀 안내](../guide/README.md). 실습의 자세한 과정은 Notion. 이 폴더는 팀이 공유할 기준 문서와 결과.

| 폴더 | 적을 내용 | 대표 파일 |
|---|---|---|
| [01-planning](01-planning/README.md) | 목표·범위·일정·역할·자원 확인 | 계획서, 일정표, 담당 안내 |
| [02-meetings](02-meetings/README.md) | 실제 회의 내용·결정·미해결 항목 | 날짜별 회의록 |
| [03-architecture](03-architecture/README.md) | 개선 전후 구성도·주소·클라우드 배치 | 본사망 설계, 서비스 구성도 |
| [04-security](04-security/README.md) | 문제 재현·개선안·같은 조건 재시험 | S01 개선 전/후 시험 |
| [05-development](05-development/README.md) | 앱의 화면·서버·DB 연결 설계 | API, DB 관계도 |
| [06-testing](06-testing/README.md) | 통신·서비스·백업·복원 등 통합 시험 | 시험 기준과 실제 결과 |
| [07-reports](07-reports/README.md) | 팀 결과·발표·개인 기여 | 최종 컨설팅 보고서 |
| [templates](templates/README.md) | 새 문서에 복제할 빈 양식 | 회의록·시험 양식 |
| [portfolio](portfolio/README.md) | 별도 포트폴리오 제작 안내 | 포트폴리오 PDF |

**문서 공통 첫머리:** 담당, 관련 작업 번호, 상태(계획/적용/시험 완료), 마지막 확인 날짜, 자세한 Notion 구간 링크. 실행 전의 계획을 시험 결과처럼 표시하지 않음.
