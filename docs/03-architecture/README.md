# 03 · 아키텍처 설계
- `as-is/`: 개선 전 구성도 및 실습 조건 (취약 설정은 격리 랩 한정)
- `to-be/`: 개선 후 구성도 및 보안 통신 정책
- `network/`: 4망 토폴로지, VLAN/CIDR/라우팅/VPN 트래픽 명세
- `cloud/`: 온프레미스↔AWS 서비스 분리·보안 경로·DR 배치

**주의:** 본사/서비스/DR/캐나다는 4개 **기능상 주요 망**이고 VLAN·서브넷은 그 안에 여러 개 배치됩니다. 모든 망에 VLAN 분리 및 VPN 종단/연계 방식을 설계하며, 반드시 모든 망끼리 풀메시 VPN을 구축하는 의미는 아닙니다.
