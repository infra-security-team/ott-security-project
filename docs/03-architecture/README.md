# 03 · 구성 설계

**작성 대상:** 팀이 함께 보아야 하는 네트워크·서버·클라우드 구성도와 통신표. 개인 실습 과정·오류 기록은 Notion 기술서.

| 파일 | 기록 내용 |
|---|---|
| [개선 전](as-is.md) | 문제가 있는 실습 환경의 구성도·주소·설정 기준 |
| [개선 후](to-be.md) | 바뀐 연결·접근 권한·보안 장치의 구성도 |
| [망 연결](network.md) | 본사·서비스·백업·캐나다의 주소, 허용 통신, VPN 경로 |
| [클라우드](cloud.md) | AWS와 자체 장비에 배치할 대상·비용·접근 경로 |

**개인 파일 예:** `m1-as-is.md`, `m5-network.md`. 첫머리에 담당·관련 작업 번호·계획/실제 적용 상태·Notion 상세 링크. 4개 주요 망 안에 여러 VLAN·서브넷이 들어갈 수 있음.
