# 06 · 통합 시험과 결과

**시점:** 각자 구축을 마친 후 망 연결·앱·보안 로그·복원 기능을 실제로 함께 확인할 때.

| 자료 | 기록 내용 |
|---|---|
| [시험 기준표](test-matrix.md) | 누가 무엇을 어떤 기준으로 확인할지. 현재 미수행 |
| [시험 양식](../templates/test-case-template.md) | 날짜·환경·입력·기대 결과·실제 결과·판정·근거 |

**결과 파일 예:** `test-dr-001.md` = 별도 환경의 DB 복원 결과. 실제 시험 후 작성하고 담당 작업 페이지에 링크. VPN 연결, DB 포트 제한, API 권한, 앱 장애, 백업 복원, 캐나다 웹 접속의 정상·실패 결과 구분. 결과가 아직 없으면 파일 없음이 정상.
