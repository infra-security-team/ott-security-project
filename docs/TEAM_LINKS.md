# 팀 공용 링크·계정·일정
[처음 화면](../README.md) · [착수 준비 #6](https://github.com/infra-security-team/ott-security-project/issues/6)

공용 공간은 **링크를 등록한 뒤 다른 팀원 계정으로 열리는지 확인**합니다. 개인 ChatGPT 파일 링크나 로컬 경로를 팀 공용 URL로 쓰지 않습니다.

| 항목 | 현재 값 | 등록·확인 |
|---|---|---|
| 팀 Notion 홈 | 미등록 | PM 공간 확인, 전원 접근 검사 |
| M1 유용수 기술서 | 미등록 | 본인 페이지 생성·URL 등록 |
| M2 윤서영 기술서 | 미등록 | 본인 페이지 생성·URL 등록 |
| M3 홍은서 기술서 | 미등록 | 본인 페이지 생성·URL 등록 |
| M4 박진혁 기술서 | 미등록 | 본인 페이지 생성·URL 등록 |
| M5 유은혜 기술서 | 미등록 | 본인 페이지 생성·URL 등록 |
| GitHub 계정 매핑 | 미등록 | 각자 계정명을 #6에 남기고 PM이 Issue Assignees 연결 |
| 실제 착수일 / 발표일 | 미확정 | 전원 합의 후 WBS·Issue 마감 반영 |
| W1 / W2 / W3 / W4 날짜 | 미확정 | PM 등록, 전원 확인 |
| GitHub Projects 보드 | 미구성 | 현재는 Issues만 사용. 추가 시 별도 상태 중복 관리 금지 |

여기에 비밀번호·토큰·VPN 키를 쓰지 않습니다. 링크가 없다면 “미등록”을 유지하고 #6에서 담당·기한을 정합니다.
