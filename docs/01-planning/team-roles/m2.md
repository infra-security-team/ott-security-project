## 지금 가장 먼저 할 일
시험 Linux·대상 SSH 서버·Wazuh 수집 경로와 Suricata 관찰 위치를 그립니다. 승인할 시험 횟수·간격·기대 경보를 정의합니다.
- 준비할 산출물: **수집·센서 배치안, 공통 증거 기준, S02 시험 설계**
- 먼저 받아야 할 정보: 각 서버의 OS·로그 종류·통신 경로
- 교차 확인: M1 (관리·수집 경로), 해당 서버 담당 (로그 대조)
- 기본 범위: 공격 실습 Linux·Wazuh·Suricata·Bastion·중앙 관제. 각 망 설정은 각 담당자가 수행.

| M2-03 | W2 | 승인된 보안 시나리오 재현·분석 | 관찰 결과·로그·설정·원인/영향 |

## 재검증 때 유지할 정상 기능
승인 관리자의 정상 SSH 로그인. 개선 전·후 같은 입력으로 검사하고 결과를 남깁니다.

S02의 필수 판단은 인증 실패 이벤트와 경보의 일치입니다. 차단을 적용했다면 차단 결과와 정상 관리자 접속을 별도로 검사합니다. Suricata는 센서 가시성을 먼저 확인합니다.
