# M1 유용수 · 본사 네트워크
[역할 목록](README.md) · [시작 Issue #1](https://github.com/infra-security-team/ott-security-project/issues/1) · [작업 작성법](../../WORK_GUIDE.md)

## 지금 가장 먼저 할 일
각 망의 VLAN·대역·VPN 종단 요청을 모아 중복을 확인하고, 본사 직원/관리 구역과 Bastion 경로를 그립니다.
- 준비할 산출물: **주소·VPN·통신 정책 초안, S01 시험 설계**
- 먼저 받아야 할 정보: 각 망 담당의 대역·필요 통신 요청
- 교차 확인: M2 (관리 경로), 각 망 담당 (VPN)
- 기본 범위: VLAN·라우팅·NAT·VPN 허브·방화벽. 게이트웨이 이중화는 선택 확장.

## 내 작업 순서
| WBS | 시점 | 할 일 | 완료 근거 |
|---|---|---|---|
| M1-01 | W1 | 설계·S01 · 본사 직원망 → 관리 서버 SSH 포트 접근 조건 작성 | 구성·시험 조건·정상 경로 검토, 미확정 항목 담당/기한 |
| M1-02 | W2 | 본사 VLAN과 VPN 허브, 왕복 경로·NAT 예외를 구성 | 정상 경로 동작·격리 확인, 설정·환경 기록 |
| M1-03 | W2 | 승인된 보안 시나리오 재현·분석 | 관찰 결과·로그·설정·원인/영향 |
| M1-04 | W3 | 개선안 작성 → 직원망의 직접 관리 접속을 제한하고 승인된 관리 경로 유지 | 검토된 정책·적용 설정 차이·롤백 방법 |
| M1-05 | W4 | 같은 조건 재시험 + 정상 기능 확인 | 전후 비교·정상 기능·잔여 위험 교차 확인 |
| M1-06 | W4 | 결과보고·시연·담당 기여 정리 | 결과 링크·재현 절차·제약 설명 |

M1-02는 COMMON-01 설계 기준선 합의 후, -03은 -02의 정상 기능 확인 후 시작합니다. -04는 -03의 증거 확보 후, -05는 개선 적용 후, -06은 결과가 정리된 후 마무리합니다.
